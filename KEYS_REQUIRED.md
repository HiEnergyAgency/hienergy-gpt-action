# Required API Keys

## HiEnergy Skill
- **HIENERGY_API_KEY**: Required for affiliate program search.
  - Get it from: https://app.hienergy.ai
  - Set it: `export HIENERGY_API_KEY="your_key"`

## Web Search
- **BRAVE_API_KEY**: Required for web search.
  - Set it via `openclaw configure --section web`
